# UI 规格（v0.1.0）

三屏 + 一个抽屉，不做导航栏、不做多标签。视觉同源 WebUI：深色底、克制的圆角、留白优先、等宽字体只用于数字。

## 1. 连接页

- 两个字段：实例地址（`host:port`，默认 http，https 自动 443）、访问 token（密文）。
- 单按钮「连接」；点击后先 `GET /api/health`（4 s 超时）判可达，再用 token 请求 `/api/auth/session` 判凭证。
- 错误就地显示：`UNAUTHORIZED` →「token 不对」；`NETWORK/TIMEOUT` →「连不上，检查地址与网络」。
- 连接成功一次性入栈，之后不再回此页（除非主动断开）。

## 2. 会话列表

- 每行：标题（单行省略）/ 副标题 `origin · engine · model` / 右端运行中绿点。
- 分组：`运行中会话 N` 在上，`其他会话 N` 在下；运行中同时有绿点与区块位置双重提示。
- 顶部：刷新、断开。不提供「新建会话」——App 管理的是平台与 WebUI 已有的会话。
- 分页：滚动到底触发 `cursor` 增量；失败不打断已有列表。
- 底部留出系统导航栏安全区（三键导航不会盖住最后一行）。
- 列表项带头像：取 WebUI「聊天平台」同源 `adapters.bots.user.avatar`，取不到退化为渐变图标。
- 长按：重命名、删除（仅 web 来源会话；平台会话弹提示「由聊天软件管理」）。
- 新建会话不在 App 内（web 会话与会话隔离，对平台聊天无意义）。

## 3. 会话详情

- 助手消息无气泡、整宽排版；用户消息右侧浅色气泡。
- 正文走 Markdown：标题、列表、粗斜体、行内码、代码块、表格、链接、图片。
- 图片：`<img src>` 在模型层已转成 `![](url)`；渲染为圆角缩略，点开全屏可缩放；相对路径按 `<base>/files/<name>` 解析，失败显示占位。
- 思考过程（`reasoning` 块）默认折叠，标题「思考过程」，展开后弱化配色。
- 工具调用按消息聚合成一块「工具调用 ×N」，展开列出每次调用的名称、完整参数（可选中）与结果（按 `toolCallId` 关联 `tool-result`）。
- 答复正文优先取 `text` 块；没有时回退到 `reply` 工具的 `input.content`（角色引擎实际发言走这条）。
- 引擎注入的内部消息（`form: notice`，如 `[memory update]`）居中弱化展示，默认两行，点击展开全文。
- 角色引擎输出：只显示 `<message>…</message>` 内的正文，`<status/>` 之类的标记不显示。
- 流式：单独气泡随 `agent/assistant-stream` 的 `text` delta 增长；`settled` 后清空并重取历史。
- 工具调用：不画甘特图，只把「正在调用 <工具名>」作为临时状态行放在流式气泡上方。
- 无输入框：平台会话的输入仍由聊天软件承担，App 只读。
- 倒序列表（最新在底部，首帧即到底部，无「下沉」动画）；向上滚到历史尽头自动再加载一页（每次 12 条，初始窗口 12 条）。
- 路由用 Cupertino 风格：即使系统是三键导航栏，左缘右滑也能返回。
- 进入前在列表页先把历史取回，详情页第一帧就有内容（debug 头部会显示 `net / paint / live` 三段耗时）。
- AppBar：中止按钮（生成中可用）、菜单（压缩上下文、分叉到新会话、重新载入）。
- 顶部状态条：`origin · engine · model · 生成中 · 实时流不可用·轮询中`。
- 实时流失败：顶部条提示「实时流不可用，改用轮询」，发送后按 1.2 s 轮询历史直到出现助手消息。

## 空态与错误

- 列表空：一行说明 + 「新建会话」按钮。
- 拉取失败且无缓存：错误码 + 重试按钮，不显示空白页。
- 401 一律回连接页并清除凭证。
