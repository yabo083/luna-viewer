# UI 规格（v0.1.0）

三屏 + 一个抽屉，不做导航栏、不做多标签。视觉同源 WebUI：深色底、克制的圆角、留白优先、等宽字体只用于数字。

## 1. 连接页

- 两个字段：实例地址（`host:port`，默认 http，https 自动 443）、访问 token（密文）。
- 单按钮「连接」；点击后先 `GET /api/health`（4 s 超时）判可达，再用 token 请求 `/api/auth/session` 判凭证。
- 错误就地显示：`UNAUTHORIZED` →「token 不对」；`NETWORK/TIMEOUT` →「连不上，检查地址与网络」。
- 连接成功一次性入栈，之后不再回此页（除非主动断开）。

## 2. 会话列表

- 数据源是插件的 `/api/platform/conversations`：每行标题用插件给的会话名（两行省略），副标题是最后一条消息，右端是最后消息时间与消息条数。
- 已加载会话（`/api/sessions` 命中）只补充状态：运行中绿点、左侧色条与排序；插件里有但未加载的会话照旧成行，没有这些标记。
- 分组：`运行中会话 N` 在上，`其他会话 N` 在下；两组内部都按最后消息时间倒序。
- 活跃窗口 `activeWindow = 3 天`（`sessions_page.dart` 顶层常量）：主列表只放最后一条消息在 72 小时内的会话（`running` 的会话无论多久都在主列表）。更早的进「归档」：主列表底部固定一行弱化的 `归档 · N`，点进去是独立子视图（AppBar 换返回箭头 + 「归档」，列表样式复用会话行，没有搜索与分组）。归档里收到新消息即自动回到主列表（行由 stream 更新触发重算，无需手动取消归档）。
- 空态：主列表无活跃但归档非空 → 「最近 3 天没有活跃会话」+ 归档入口；两者都空才显示「暂无活跃会话」。
- 实时：订阅 `/api/platform/stream`——已有会话就地更新计数/最后一条/时间，新会话补一次会话表后插入，不重排整页、不动滚动位置；同一帧内的多帧合并成一次重建；下拉刷新是全量对齐。
- 顶部：搜索、刷新、设置。点搜索图标时标题位直接变形为输入框（180ms 淡入 + 横向 SizeTransition），AppBar 高度不变、列表位置不动；搜索态 actions 换成刷新 + ✕，退出清空关键词并收键盘。过滤按标题（原始/紧凑）、引擎、模型；无结果给「清空搜索」。
- 设置抽屉：外观（主题）/ 更新（检查更新、当前版本）/ 关于（诊断信息复制）/ 开发者（平台与引擎信息开关）/ 危险区（断开连接，二次确认）。
- 已加载会话分页：滚动到底触发 `cursor` 增量（只影响状态与运行中排序的完整性，插件会话表一次取全）；失败不打断已有列表。
- 底部留出系统导航栏安全区（三键导航不会盖住最后一行）。
- 列表项带头像：优先用插件给的会话 `avatar`，其次 `adapters.bots.user.avatar`，都没有退化为渐变图标。
- 点击即进详情：`HapticFeedback.selectionClick()` + 同步推路由，推路由前不等待任何网络请求；会话行的 `ValueKey` 等于会话键，实时帧重排只移动元素，不会把手指下的 `InkWell` 重建掉。
- 长按：重命名、删除（仅 web 来源会话；平台会话弹提示「由聊天软件管理」）；未加载的会话（插件里有、`/api/sessions` 里没有）只提示「尚未被 ChatLuna 加载，只能查看消息」。
- 新建会话不在 App 内（web 会话与会话隔离，对平台聊天无意义）。

## 3. 会话详情

- 视角是 bot 视角：`dir=out`（机器人的回复/指令响应）在**右侧主色气泡**，`dir=in`（我/群友）在**左侧中性气泡**；两侧都走 markdown 与富媒体，气泡最大宽度 86%。
- 每条消息 = 头像槽（28，左右各一）+ 发送者名（小字弱化）+ 气泡；`out` 用 `AssistantAvatar`，`in` 用真实头像（缺失时首字母圆头像）。
- 分组：同一发送者 5 分钟内的连续消息只保留第一条的头像与名字，后续留空头像槽、缩进对齐、间距 8dp；换人/超时/跨天/插入框架块后重新起组（间距 16dp）。
- 时间：`HH:mm` 放在气泡右下角（弱化）；缺失就不画，不影响布局。
- 跨天插入日期分隔条（`今天`/`昨天`/`YYYY-MM-DD`），弱化居中。
- 正文走 Markdown：标题、列表、粗斜体、行内码、代码块、表格、链接、图片。
- 图片：`<img src>` 在模型层已转成 `![](url)`；渲染为圆角（12）缩略，上限 260×320，点开全屏可缩放；相对路径按 `<base>/api/workspace?path=` 解析，失败显示占位。
- 思考过程（`reasoning` 块）默认折叠，标题「思考过程」，展开后弱化配色。
- 消息只来自插件：进入即取 `platform/messages` 最新 50 条（时间升序），向上滚到尽头用 `before=<最早一条的时间>` 取更早一页；实时帧来自 `platform/stream`，按会话键过滤（两边都过 `normalizeConversationKey`），消息 id 去重。
- 框架消息（wake / memory / 工具摘要等）只在**已加载会话**里补：首帧之后额外拉一次 `/api/sessions/:id/messages`，只收 `isFramework` 的条目，以居中单卡片插回时间线；增量走 `/api/sessions/:id/events`，同样只收框架类。未加载的会话既不拉日志也不显示框架块。
- 框架块与平台消息合并成**一条时间线**（`lib/features/chat/timeline.dart` 的纯函数 `mergeTimeline`）：时间升序；同一时刻平台消息在前、框架块在后，因此框架块落在它当轮真实对话之前的原位置，不会被丢到列表底部。
- 框架块定锚：服务端给了时戳就用它；没给就夹在日志里前后两条平台消息之间（前一条 +1ms / 后一条 −1ms），日志开头那批取后一条 −1ms。增量（`/events`）没有时戳时取「最近一条平台消息 + 1ms」，设备时钟偏快也不会越过这一轮的回复。锚点存进条目本身，翻页（`before`）只往前追加更早的消息，位置不漂；增量插在视口上方时不改滚动位置、不涨未读。
- 框架块去重：正文压掉全部空白后与平台消息比较，且时间相差 ≤ 3s 视为同一条（指令类消息既是平台发言又是框架消息，只画一次）。
- 无输入框：平台会话的输入仍由聊天软件承担，App 只读。
- 倒序列表（最新在底部，首帧即到底部，无「下沉」动画）；向上滚到最早一条自动取更早一页（每页 50 条，游标是最早一条的时间）。
- 首屏只等 `platform/messages` 首页；`/live`、会话日志、`/events`、`/api/platform/stream` 全部 post-frame 再连。
- 路由用 Cupertino 风格：即使系统是三键导航栏，左缘右滑也能返回。
- debug 头部显示 `net / paint / live / msg / fw`：`paint` 是点击到首帧上屏的本地耗时。
- AppBar：中止按钮（生成中可用）、菜单（压缩上下文、分叉到新会话、重新载入）——仅已加载会话显示，未加载的会话只剩标题。
- 顶部信息栏（仅已加载会话）：bot 名（带头像）/ `origin · engine`（开发者开关）/ 模型 / 状态灯。
- 已加载会话才有信息栏与状态胶囊：待机（静态灰点）/ 思考中（主色呼吸点 + 消息区三点）/ 回复中（静态主色点），由 `/api/sessions/:id/live` 驱动；未加载的会话显示轻量条（bot · 平台 · 未加载），命中会话后切换为完整信息栏并接入 /live，也没有中止/压缩/分叉/切模型。
- 流式：单独气泡随 `agent/assistant-stream` 的 `text` delta 增长（右侧主色，与正式气泡同款）；`settled` 后清空，落库的那条由平台流补成正式气泡（不再重取历史）。
- `/live` 断开：状态回到待机（无法得知生成状态），消息仍由平台流补上。
- 新消息通过 `/api/platform/stream` 进入；贴底自动跟随，否则只累加 FAB 未读；断线退避 1→2→4→8→16→30 s。

## 空态与错误

- 列表空：一行说明 + 「新建会话」按钮。
- 拉取失败且无缓存：错误码 + 重试按钮，不显示空白页。
- 401 一律回连接页并清除凭证。
